# BouNodeKiller

BouNodeKiller es una herramienta para Windows que ayuda a encontrar procesos de Node.js, ver qué están ejecutando y cerrar uno, varios o todos.

## Qué hace

- lista procesos `node.exe` y `nodejs.exe`
- muestra la línea de comandos completa
- identifica el script o destino que se está ejecutando
- muestra el usuario, el PID, el proceso padre y la hora de inicio
- muestra el directorio de trabajo de lanzamiento detectado
- permite cerrar el proceso seleccionado
- permite cerrar todos los procesos de Node a la vez

## Interfaz

- búsqueda instantánea
- tabla clara con información útil
- ventana "Acerca de" con versión y enlaces del proyecto
