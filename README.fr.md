# BouNodeKiller

BouNodeKiller est un outil Windows pour repérer les processus Node.js, voir ce qu'ils exécutent, puis en fermer un, plusieurs ou tous.

## Ce que l'application fait

- liste les processus `node.exe` et `nodejs.exe`
- affiche la ligne de commande complète
- identifie le script ou la cible lancée
- montre l'utilisateur, le PID, le parent et l'heure de lancement
- affiche le répertoire de lancement détecté
- permet de tuer un processus sélectionné
- permet de tuer tous les processus Node d'un coup

## Interface

- recherche instantanée
- tableau clair avec les informations utiles
- fenêtre "À propos" avec version et liens du projet
